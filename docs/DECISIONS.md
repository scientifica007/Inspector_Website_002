# قرارات البناء المستقل

مصدر المتطلبات: طلب المستخدم في هذه التجربة فقط. المستودع الوحيد: scientifica007/Inspector_Website_002.
الأساس: ff957b5a10a3d7dd20dea8b406e4cdc7a6da05ba، وفيه README من سطرين محفوظان.

1. Django 5.2 LTS وصفحات خادم؛ خدمات صريحة للعمليات المركبة، وليس منطقًا موزعًا على الأزرار.
2. مرجع مستقل بشجرة ومعرّفات UUID. لا مرجع عالمي ولا إصدار ينهي بقية المراجع.
3. الزيارة تنسخ المرجع وهوية المؤسسة والمفتش؛ معرّفات المصدر بيانات تاريخية وليست علاقات حذف متسلسل.
4. كل عقد المرجع مجمّدة في الزيارة، لكن النطاق يبدأ فارغًا. الأسلاف السياقيون لا يدخلون في التقدم.
5. أصل العنصر يسجل عند إدخاله الأول ولا يستبدل عند إضافة دليل أو تكليف. المحتوى المحلي داخل الزيارة فقط.
6. الأدلة اختيارية؛ يحفظ كل تطبيق نسخة وتوقيعًا وتقرير العناصر المتخطاة. لا استيراد متأخر لمحتوى المرجع الحي.
7. التكليفات الإدارية الخاصة بمسودة زيارة تصدر ذريًا. كل التزاماتها منفصلة؛ القيود الفعلية = الأساسية OR التكليفات السارية.
8. completion_required مستقل عن scope_locked: يمكن استبعاد عنصر مطلوب غير مقفل أثناء المسودة، لكن يجب استرجاعه وإنجازه قبل الإكمال.
9. الفرع هيكلي؛ إلزام إنجازه يمتد للوصف والبنود الموجودة في اللقطة المجمدة عند الإصدار. الفرع الفارغ لا يضيف مقامًا وهميًا للتقدم.
10. لا حذف لمسودة غير مملوكة، حتى بواسطة الإدارة. للإدارة قراءة الزيارات المشتركة إداريًا وإصدار التكليفات فقط؛ لا تعديل نتائج غيرها.
11. الإدارة لا تتصفح المراجع الشخصية غير المرسلة. تراجع فقط النسخة المرسلة. القبول ينشئ مرجعًا مشتركًا بمعرّفات جديدة وخريطة إلى المصدر.
12. الزيارة المكتملة مختومة بمحتوى تصدير ثابت. سنحمي التعديلات على مستوى الخدمات وقاعدة البيانات (SQLite / PostgreSQL).
13. لا تاريخ إنشاء تصدير جديد؛ JSON مرتب، مخطط versioned، والبيانات المجمدة تظل مستقلة عن الحسابات والمصادر الحية.
14. المؤسسات المستخدمة لا تحذف؛ يمكن تعطيلها. حذف المرجع لا يمس الزيارات أو الاقتراحات أو تطبيقات الأدلة السابقة.
15. بيانات التجربة ينشئها أمر اختياري لا يكتب فوق السجلات الموجودة ولا يعيد تعيين كلمات المرور.
16. استضافة Sites المتاحة تتطلب Cloudflare Worker ESM ومستودع مصدر تديره الخدمة. لا يتوافق هذا مع Django التقليدي وحصر المستودع؛ لا نسجل موقعًا بديلًا ولا ننشر واجهة صورية. التسليم هنا هو التطبيق في المستودع وDraft PR.
